# UTM 추적 가이드

#### UTM 분석이란?

Urchin Tracking Module의 줄임말로, 내 사이트의 어떤 페이지에 들어온 사용자가 어디서 유입되었는지 알려주는 도구입니다. 많은 마케터가 디지털 마케팅 성과 측정을 위해 사용합니다. 외부에서 사용자가 클릭한 광고 또는 배너 링크에 정보를 넣으면, 도착한 페이지에서 이 정보를 수집해 분석에 활용합니다. 쉽게 말해 링크에 이름표를 달아주는 것입니다.

{% hint style="info" %}
에이스카운터의 UTM 분석은 세션의 유입부터 전환까지 실시간으로 처리하기 때문에, 세션 유지시간(약 30분)이 지나면 바로 데이터를 확인할 수 있습니다.
{% endhint %}

#### UTM 설정 방법

네이버, 카카오 등 광고 플랫폼에서 광고를 만들 때 광고 소재의 도착 페이지 URL에 UTM 정보를 추가하여 분석할 수 있습니다. `?` 기호를 활용해 UTM 파라미터를 링크에 직접 붙입니다.

```
https://도착페이지URL?UTM파라미터=값
```

여러 파라미터를 구분할 때는 `&` 기호를 사용합니다.

```
https://도착페이지URL?UTM파라미터1=값1&UTM파라미터2=값2
```

{% hint style="info" %}
이러한 방식은 구글 공식 가이드에서 수동(Manual) 방식으로 분류되며, 구글 애널리틱스 리포트에서 확인할 수 있습니다. 동일한 데이터를 에이스카운터에서 더 빠르고 정확하게 확인할 수 있습니다. (참고: 구글 Ads, Search Console 등은 자동으로 이름표를 붙이는 자동 방식입니다.)
{% endhint %}

#### 주요 UTM 파라미터

분석을 위해 필수로 포함되어야 하는 3가지 파라미터와, 많이 쓰이는 2개 파라미터를 소개합니다.

| 파라미터          | 값(예시)                          | 설명                        | 필수 여부 |
| ------------- | ------------------------------ | ------------------------- | ----- |
| utm\_source   | google, naver, facebook        | 어떤 채널에서 사용자가 링크를 클릭했는지    | 필수    |
| utm\_medium   | cpc, newsletter, referral      | 클릭한 링크가 담겨있는 매체의 정보, 광고유형 | 필수    |
| utm\_campaign | 2024\_sales, winter\_promotion | 집행한 광고의 마케팅 캐페인           | 필수    |
| utm\_content  | 결제바지\_할인                       | 하나의 캐페인에서 여러 광고 소재를 구분    | 선택    |
| utm\_term     | 청바지, 결제바지                      | 광고 검색어 키워드                | 선택    |

{% hint style="danger" %}
파라미터 값은 대소문자를 구분합니다.
{% endhint %}

모든 파라미터의 종류는 [구글 공식가이드 문서를](https://support.google.com/analytics/answer/10917952?hl=ko#zippy=%2C%EC%9D%B4-%EB%8F%84%EC%9B%80%EB%A7%90%EC%97%90%EC%84%9C%EB%8A%94-%EB%8B%A4%EC%9D%8C-%EB%82%B4%EC%9A%A9%EC%9D%84-%EB%8B%A4%EB%A3%B9%EB%8B%88%EB%8B%A4) 참고해주세요.
