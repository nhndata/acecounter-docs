# 가입하기

{% hint style="info" %}
쇼핑몰 호스팅(CAFE24·아임웹·샵바이·고도몰 등)을 사용 중이라면 '호스팅으로 가입하기'를 확인해 주세요. 이미 스크립트가 설치되어 있다면 가입 절차 없이 바로 이용할 수 있습니다.
{% endhint %}

### 직접 가입하기

1. 홈페이지(acecounter.com)에서 '무료체험 시작하기' 버튼을 클릭합니다.

![](../.gitbook/assets/AC_main.png)

2. 분석 데이터를 확인하고 연락받을 실무 담당자 정보를 입력합니다. 사이트 주소는 `https://`를 제외하고 입력합니다.

![](../.gitbook/assets/signup.png)

3. 가입이 완료되면 분석을 위한 스크립트 설치 대행을 신청할 수 있습니다.

![](../.gitbook/assets/done.png)

{% tabs %}
{% tab title="일반 웹사이트" %}
스크립트 설치를 위해 FTP 접속 정보가 필요합니다. 홈페이지 제작 업체의 개발자를 통해 확인한 정보를 입력해 주세요.

![](../.gitbook/assets/general.png)
{% endtab %}

{% tab title="호스팅(CAFE24/메이크샵/고도몰/아임웹 등)" %}
쇼핑몰 관리자에 접속할 수 있는 로그인 정보를 입력해 주세요.

![](../.gitbook/assets/hosting.png)
{% endtab %}
{% endtabs %}

### 호스팅으로 가입하기

CAFE24 · 아임웹 · 샵바이 등 호스팅으로 쇼핑몰을 운영 중이라면, 가입과 동시에 스크립트가 자동으로 설치됩니다.

{% tabs %}
{% tab title="CAFE24" %}
1. CAFE24 앱스토어의 에이스카운터 페이지에서 '설치하기'를 클릭합니다.

![](../.gitbook/assets/cafe24-1.png)

2. 이용 약관에 동의하면 앱이 설치됩니다.

![](../.gitbook/assets/cafe24-2.png)

3. 상단 '서비스 신청' 버튼을 눌러 분석할 쇼핑몰과 버전을 선택합니다.

![](../.gitbook/assets/cafe24-3.png)

4. 개인정보 처리방침·이용약관에 동의하고 쇼핑몰을 선택한 뒤 '서비스 신청'을 클릭하면 스크립트가 자동으로 설치됩니다.

![](../.gitbook/assets/cafe24-4a.png)

![](../.gitbook/assets/cafe24-4b.png)

여러 쇼핑몰을 운영 중이라면 같은 화면의 '서비스 추가'로 추가 신청이 가능합니다.
{% endtab %}

{% tab title="아임웹" %}
1. 사이트 관리자 왼쪽 메뉴에서 \[통계 > 부가서비스]를 클릭합니다.

![](../.gitbook/assets/imweb-1.png)

2. 에이스카운터 '서비스 신청' 버튼을 클릭합니다.
3. 사이트 기본 정보, 서비스 선택, 이용약관 동의를 입력합니다.

![](../.gitbook/assets/imweb-2.png)

4. '신청하기' 버튼을 클릭하면 스크립트 설치가 자동으로 진행됩니다.
{% endtab %}

{% tab title="샵바이" %}
1. 샵바이 앱스토어의 에이스카운터 페이지에서 '설치하기'를 클릭합니다.

![](../.gitbook/assets/shopby-1.png)

2. 쇼핑몰을 선택해 '설치'를 클릭하고, 권한에 전체 동의한 뒤 다시 '설치'를 클릭합니다.

![](../.gitbook/assets/shopby-2.png)

3. 설치 완료 후 '앱 리스트 가기'에서 에이스카운터를 실행합니다.

![](../.gitbook/assets/shopby-3a.png)

![](../.gitbook/assets/shopby-3b.png)

4. 쇼핑몰 정보를 확인하고 '무료체험 시작하기'를 클릭하면 가입과 동시에 스크립트가 설치됩니다.

![](../.gitbook/assets/shopby-4.png)
{% endtab %}

{% tab title="고도몰" %}
1. NHN Commerce 쇼핑몰 목록에서 고도몰 관리자로 이동합니다.

![](../.gitbook/assets/godomall-1.png)

2. 상단 \[통계] 메뉴에서 '에이스카운터 신청/관리'를 클릭합니다.

![](../.gitbook/assets/godomall-2.png)

3. 가입 정보와 이용약관 동의를 입력하고 '서비스 신청'을 클릭하면 스크립트가 자동으로 설치됩니다.

![](../.gitbook/assets/godomall-3.png)
{% endtab %}

{% tab title="플렉스지(위드소프트)" %}
1. 관리자 상단 \[통계] 메뉴에서 '에이스카운터'를 클릭합니다.

![](../.gitbook/assets/flexge-1.png)

2. 가입 정보를 확인하고 '에이스카운터 바로 이용하기'를 클릭하면 스크립트가 자동으로 설치됩니다.

![](../.gitbook/assets/flexge-2.png)
{% endtab %}
{% endtabs %}
