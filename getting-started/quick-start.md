# 핵심 지표 확인하기

가입과 초기 설정(스크립트 설치, 전환페이지 등록)을 마치셨다면, 아래 5가지 핵심 지표부터 확인해 보세요.

1. **대시보드**(\[분석통계 → 대시보드]) — 접속수, 유입 경로, 콘텐츠 현황을 한눈에 확인합니다.

![](https://2270058976-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FsZPVuRtLUd0kyai9OY4p%2Fuploads%2FkAHTbDD1mulMREWzjqTT%2F%EB%8C%80%EC%8B%9C%EB%B3%B4%EB%93%9C.png?alt=media)

2. **접속 현황과 유입 출처**(\[분석통계 → 접속현황], \[분석통계 → 유입경로]) — 시간대별 방문자 수, 채널별 유입수·전환수를 확인합니다.

![](https://2270058976-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FsZPVuRtLUd0kyai9OY4p%2Fuploads%2FblLEwywuig5qeS6jnp2a%2F001_%EB%B0%A9%EB%AC%B8%EC%88%98.png?alt=media)

![](https://2270058976-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FsZPVuRtLUd0kyai9OY4p%2Fuploads%2FGHTEd8eR829CI4Hq5iSY%2F002_%EC%9C%A0%EC%9E%85%EC%B6%9C%EC%B2%98.png?alt=media)

3. **검색광고 성과와 부정클릭**(\[분석통계 → 검색광고 효과]) — 광고상품·검색어별 유입과 전환을 확인하고, \[중복 유입 간격] 메뉴에서 의심 IP를 점검합니다.

![](https://2270058976-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FsZPVuRtLUd0kyai9OY4p%2Fuploads%2FkgUqk6Z8wMfrFlWuycn5%2F003_%EA%B2%80%EC%83%89%EA%B4%91%EA%B3%A0%EA%B2%80%EC%83%89%EC%96%B4.png?alt=media)

![](https://2270058976-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FsZPVuRtLUd0kyai9OY4p%2Fuploads%2FouGOZoRYPZ4aqUn3kJMg%2F004_%EB%B6%80%EC%A0%95%ED%81%B4%EB%A6%AD.png?alt=media)

4. **SNS·디스플레이 광고 분석** — 광고 파라미터가 없는 매체는 에이스카운터 광고 코드(캠페인 생성 후 코드 발급)로 성과를 추적합니다.

![](https://2270058976-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FsZPVuRtLUd0kyai9OY4p%2Fuploads%2Fc0GhsH69so9Ym04hwbSM%2F005_%EB%94%94%EC%8A%A4%ED%94%8C%EB%A0%88%EC%9D%B4.png?alt=media)

5. **구매·매출 분석**(Commerce 버전, \[분석통계 → 구매자 → 구매분석]) — 전체 매출액, 시간대·일자별 매출, 제품별 매출을 확인합니다.

![](https://2270058976-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FsZPVuRtLUd0kyai9OY4p%2Fuploads%2FXXH7S6RdfjPZnqFqpXpZ%2F%EA%B5%AC%EB%A7%A4%EC%9E%90.png?alt=media)

앞으로도 방문자 분석, 광고 성과 분석, 전환·매출 분석을 지속적으로 확인하며 사이트와 마케팅 성과를 개선해 보세요.
