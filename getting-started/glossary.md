# 분석 지표 용어집

에이스카운터 통계와 데이터에서 사용하는 용어를 정리했습니다.

#### 페이지뷰 · 방문수

**페이지뷰**는 방문자가 웹페이지를 열어본 횟수입니다(새로고침, 이전/다음 이동 시에도 증가). **방문수**는 세션이 종료된 뒤 새로 방문했을 때 증가하며, 신규방문수와 재방문수의 합입니다. **순방문수**는 시간/일간/주간/월간 등 기준별로 중복 방문을 제외한 방문수입니다.

#### 유입수 · 전환수

**유입수**는 세션 유지 여부와 관계없이 유입출처(리퍼러)가 달라질 때마다 추가로 집계됩니다. **전환수**는 방문자가 웹사이트의 최종 목표(구매완료, 회원가입 완료 등)에 도달한 횟수로, \[설정 > 페이지 > 전환 페이지]에 등록한 페이지 도달 시 증가합니다.

#### 쿠키 · 세션

**쿠키**는 방문자의 컴퓨터에 남는 작은 기록 파일로, 신규·재방문, 순방문, 중복 유입 등 분석의 기준이 됩니다. **세션**은 방문자를 구분하는 고유값으로 브라우저 접속 시작부터 종료(또는 40분간 활동 없음) 시 종료됩니다.

#### 반송수 · 반송률

**반송수**는 방문자가 랜딩 페이지 외 다른 페이지로 이동하지 않고 바로 이탈한 경우입니다. **반송률(%) = 반송수 / 유입수 × 100**으로, 높을수록 랜딩 페이지의 콘텐츠나 UI 개선이 필요할 수 있습니다.

#### 직접유입

유입출처(리퍼러)가 없는 유입입니다. 주소창 직접 입력, 즐겨찾기, 바탕화면 바로가기, 일부 배너광고, 모바일 앱 내 링크, 문자·QR코드 등으로 방문한 경우가 해당됩니다.

#### 내부유입

사이트 내부에서 유입이 시작된 경우입니다. 분석 스크립트가 없는 페이지로 처음 방문한 뒤 스크립트가 있는 페이지로 이동한 경우, 40분간 활동이 없어 세션이 종료된 뒤 다시 이동한 경우, 쿠키를 차단한 상태에서 페이지를 이동한 경우에 발생합니다. 내부유입 비율이 높다면 특정 페이지에 스크립트 설치가 누락되지 않았는지 확인해 보세요.

#### FTP

웹페이지 소스에 분석 스크립트를 설치하려면 FTP 접속 정보(호스트, 포트, 아이디, 비밀번호)가 필요합니다. 알FTP, FileZilla 등의 FTP 클라이언트로 접속해 파일을 수정·업로드할 수 있으며, 설치가 어려운 경우 최초 1회 무료 설치 대행을 신청할 수 있습니다.

#### 검색엔진(키워드광고 제외) · 검색어없음

**검색엔진** 유입은 네이버·다음·구글 등에서 광고 영역이 아닌 일반 검색 결과(사이트 주소, 웹문서 등)를 통해 방문한 경우입니다. **검색어없음**은 지식인·지도·건강 페이지 등을 거치거나 구글의 리다이렉트 구조 때문에 유입출처 URL에 검색어 파라미터가 남지 않아 검색어를 알 수 없는 경우입니다.

#### 매체정보없음

검색광고 클릭 시 유입출처 URL로 광고 매체(예: 네이버)를 판단하는데, 추적 URL 파라미터는 남아있지만 유입출처 URL이 없는 경우(예: 파라미터가 포함된 URL을 즐겨찾기한 경우) 또는 모바일 등 환경에서 브라우저가 유입출처를 전달하지 못하는 경우 '매체정보없음'으로 분석됩니다.

#### 리퍼러 · 파라미터 · 쿼리

리퍼러(Referer)는 방문자를 사이트로 연결해 준 이전 페이지 주소로, 유입출처 분석의 기준이 됩니다. **파라미터**는 URL에 담긴 "키=값" 형태의 매개변수로, 광고 채널·소재 등을 구분하는 데 쓰입니다. **쿼리**는 검색창에 입력한 키워드가 담기는 파라미터(예: `query=`)를 가리키며, 데이터 조회 조건을 뜻하는 말로도 쓰입니다.
