# 버전 선택하기

에이스카운터는 **Business**와 **Commerce** 두 가지 버전으로 제공됩니다. 내 사이트 목적에 맞는 버전을 확인해보세요.



{% columns %}
{% column width="50%" %}
#### Business

방문자 행동과 전환을 중심으로 웹사이트 성과를 분석할 수 있습니다.

브랜드 웹사이트, 병원, 보험, 서비스업 등 상담·문의와 같은 전환을 관리하는 사이트에 적합합니다.
{% endcolumn %}

{% column width="50%" %}
#### Commerce

방문자 행동부터 구매 경로와 매출까지 커머스 성과를 분석할 수 있습니다.

온라인 쇼핑몰, 회원제 커머스 등 상품 구매와 매출 데이터를 함께 분석해야 하는 사이트에 적합합니다.
{% endcolumn %}
{% endcolumns %}
