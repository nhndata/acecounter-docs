# API 안내 및 신청

에이스카운터로 웹 분석을 이용 중인 고객사 중, 원본에 가까운 로그 데이터를 자체 시스템에서 활용하려는 고객사를 위한 서비스입니다. 사내 BI·데이터 웨어하우스로 적재해 자체 분석하거나, 광고·마케팅 성과를 자사 지표와 결합하거나, 리포트 자동화 파이프라인을 구성할 때 활용하실 수 있습니다.

#### 제공범위

발급받은 **API 키**로 요청하면, 자사의 **일별 웹로그 데이터**를 CSV 파일로 내려받을 수 있습니다.

* **일 단위 제공** — 매일 전날 데이터가 자동으로 준비됩니다.
* **CSV(gzip 압축)** — UTF-8(BOM) 인코딩이라 Excel에서 바로 열어도 한글이 정상 표시됩니다.
* **컬럼 명세 동봉** — 각 데이터 종류의 컬럼 의미를 담은 명세서 링크가 응답에 함께 제공됩니다.
* **자사 데이터로 한정** — API 키에 연결된 계정의 데이터만 조회됩니다.
