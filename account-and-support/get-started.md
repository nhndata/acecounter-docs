# 구독 시작하기

### 1. 계약하기

{% stepper %}
{% step %}
#### 구독 관리 메뉴 진입

다음 이용 상태인 경우 \[구독 관리 메뉴]를 클릭하면 계약 화면이 표시됩니다.

* 이용 상태: `무료 이용 중`, `무료 종료`, `구독 종료`
* (기존 요금제 사용자) 이용 상태: `유료 이용 중`, `유료 종료`
{% endstep %}

{% step %}
#### 결제 주기 선택

이용 요금과 추가 요금 청구 방식을 확인한 후 **월 구독 / 연 구독**을 선택합니다.

{% hint style="success" %}
연 구독을 선택하면 20% 할인이 추가로 적용됩니다.
{% endhint %}
{% endstep %}

{% step %}
#### 카드 등록 및 계약 완료

내용을 확인하고 계약하기 버튼을 클릭해 카드 등록을 진행하면 계약이 완료됩니다.

* `무료 이용 중`, `유료 이용 중` 고객: 잔여 이용 기간이 끝난 다음 날 결제가 진행되며, 그 시점부터 구독 이용 기간이 시작됩니다.
* `무료 종료`, `구독 종료`, `유료 종료` 고객: 계약과 동시에 결제가 이뤄지며, 당일 구독 이용 기간이 시작됩니다.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
에이스카운터는 카드 비밀번호를 요구하지 않지만, 이미 외부에서 비밀번호 오류 횟수를 초과한 카드는 등록이 실패할 수 있습니다.
{% endhint %}

{% hint style="warning" %}
법인 카드도 등록할 수 있으나, 개인 명의로 발급된 법인 카드는 등록되지 않습니다.
{% endhint %}

### 2. 카드 변경하기

{% stepper %}
{% step %}
#### 구독 정보 화면 진입

계약을 완료한 서비스는 \[구독 관리 메뉴]를 클릭하면 현재 이용 중인 구독 정보 화면이 표시됩니다.
{% endstep %}

{% step %}
#### 카드 변경

구독 정보 화면 하단의 결제 카드 항목에서 \[변경하기] 버튼을 클릭합니다.
{% endstep %}

{% step %}
#### 변경 완료

카드를 수정하면 다음 결제일부터 수정된 카드로 결제가 진행됩니다.
{% endstep %}
{% endstepper %}

{% hint style="danger" %}
결제 실패로 인해 카드를 변경한 경우, 변경 즉시 해당 카드로 결제를 재시도합니다.
{% endhint %}

### 3. 요금 결제 방식

{% hint style="success" %}
연 결제 시 월 결제 대비 20% 할인된 금액으로 이용할 수 있습니다.
{% endhint %}

매월 또는 매년 정기 결제일에 정기 요금과 추가 요금이 함께 청구됩니다.

| 구분    | 대상 기간              | 방식 |
| ----- | ------------------ | -- |
| 정기 요금 | 이번 달 사용 기간         | 선불 |
| 추가 요금 | 지난달 사용 기간 중 초과 사용량 | 후불 |

* 1개월 단위 기간 동안 보장 페이지뷰 사용량을 초과하면 추가 요금이 부과됩니다.
* 추가 요금은 10만 PV 구간 단위로 부과됩니다.

<figure><img src="https://2270058976-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FsZPVuRtLUd0kyai9OY4p%2Fuploads%2FpcCddywaQl0MSjVkfUJ2%2Fpricing-image.png?alt=media" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
월 결제는 매월 같은 날짜에 결제되며, 다음 달에 해당 날짜가 없으면 가장 가까운 빠른 날짜에 결제됩니다. (예: 1월 31일 → 2월 29일 → 3월 31일 → 4월 30일 → ...) 연 결제는 매년 같은 날짜에 결제됩니다. (예: 2025년 1월 31일 → 2026년 1월 31일 → 2027년 1월 31일 → ...)
{% endhint %}

### 4. 요금 테이블

* 무료 이용 기간 동안의 PV 사용량을 기준으로 견적 요금이 산정됩니다.
* 견적 요금을 기준으로 보장 페이지뷰와 요금 구간을 선택할 수 있습니다. (1구간 상하향 가능)
* 구간은 10만 PV 단위로 상향되며, 이용 중인 버전에 따라 요금이 다릅니다.

| 구간   | 보장 페이지뷰                 | Business | Commerce |
| ---- | ----------------------- | -------- | -------- |
| 1구간  | 0 \~ 10만 PV 이하          | 30,000원  | 50,000원  |
| 2구간  | 10만 PV 초과 \~ 20만 PV 이하  | 60,000원  | 100,000원 |
| 3구간  | 20만 PV 초과 \~ 30만 PV 이하  | 90,000원  | 150,000원 |
| ...  | ...                     | ...      | ...      |
| 10구간 | 90만 PV 초과 \~ 100만 PV 이하 | 300,000원 | 500,000원 |
| 협의   | 100만 PV 초과              | 협의 요금    | 협의 요금    |

{% hint style="info" %}
구독 요금제는 보장 페이지뷰를 기본 대비 20% 추가로 제공합니다.
{% endhint %}

### 5. 추가 요금 안내

추가 요금은 보장 페이지뷰를 초과한 페이지뷰를 기준으로 10만 PV 단위로 부과되며, 단가는 1개 구간 요금과 동일합니다. (Business 30,000원 / Commerce 50,000원)

| 초과 페이지뷰 | 부과 단위        | 부과 횟수 |
| ------- | ------------ | ----- |
| 9만 PV   | 10만 PV 단위 1개 | 1회    |
| 12만 PV  | 10만 PV 단위 2개 | 2회    |
| 19만 PV  | 10만 PV 단위 2개 | 2회    |
| 21만 PV  | 10만 PV 단위 3개 | 3회    |

### 6. 알맞은 요금을 선택하는 방법

{% tabs %}
{% tab title="요금 상향 추천" %}
이벤트 프로모션이 잦은 커머스/쇼핑몰에 적합합니다.

동일한 PV가 발생한다고 가정하면, 추가 요금이 발생하는 것보다 기본 요금의 보장 범위를 상향하는 편이 더 저렴합니다.

**예시: 이번 달 총 23만 PV를 사용한 경우**

| 구분     | 비용 계산                                    | 결제 요금                                     |
| ------ | ---------------------------------------- | ----------------------------------------- |
| 1구간 고객 | 보장 12만 PV(20% 혜택) + 초과 11만 PV(10만 단위 2회) | 총 90,000원 (구독 요금 30,000원 + 초과 요금 60,000원) |
| 2구간 고객 | 보장 24만 PV(20% 혜택) + 초과 0                 | 총 60,000원 (구독 요금 60,000원)                 |

구간을 높이면 추가 요금 발생을 방지하고 보장 페이지뷰도 늘어나지만, 무조건 유리한 것은 아니므로 충분히 검토 후 선택하세요.
{% endtab %}

{% tab title="요금 유지 추천" %}
특정 시즌이나 공휴일/기념일에만 트래픽이 급증하는 사이트에 적합합니다.

기존 요금을 유지하다가 해당 기간에만 추가 요금을 지불하는 편이 장기적으로 평균 요금이 더 저렴할 수 있습니다.
{% endtab %}

{% tab title="요금 하향 추천" %}
견적 요금 측정 기간에 일시적인 이벤트로 트래픽이 과다하게 측정된 경우에 적합합니다.

견적 요금이 평소보다 과다하게 산정되었다고 판단되면 구간을 낮추면 더 저렴하게 이용할 수 있습니다.
{% endtab %}
{% endtabs %}

{% endhint %}
