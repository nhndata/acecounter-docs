# 구독 종료 안내

#### 구독이 종료되는 경우

구독은 사용자가 종료를 신청하거나, 결제 실패로 인해 자동으로 종료됩니다.

{% tabs %}
{% tab title="구독 종료 신청" %}
고객은 언제든지 결제를 중단하기 위해 종료를 신청할 수 있습니다.

1. 이용 중인 서비스의 \[구독 관리 메뉴]를 클릭하면 현재 구독 정보 화면이 표시됩니다.
2. 구독 정보 화면 하단의 \[구독 종료] 섹션에서 버튼을 클릭합니다.

{% hint style="warning" %}
추가 요금 미납이 있는 경우, 구독을 재개하려면 미납 요금을 먼저 결제해야 합니다.
{% endhint %}
{% endtab %}

{% tab title="카드 결제 실패로 인한 자동 종료" %}
비정상 카드 또는 결제 오류로 결제가 처리되지 않은 경우, 정기 결제일 다음 날부터 일주일간 매일 오전 9시경 결제를 재시도합니다.

* 결제 기한이 종료될 때까지 카드를 재등록하지 않으면 서비스가 자동으로 종료됩니다.
* 결제 기한 종료 전에 카드를 재등록하면 즉시 결제를 시도하며, 성공 시 기존 계약이 유지됩니다.
{% endtab %}
{% endtabs %}

#### 환불 규정

결제가 완료된 기간은 구독 종료일까지 사용하는 것을 원칙으로 하며, 원칙적으로 환불은 진행되지 않습니다.

단, 연 구독 이용 중 특정 달까지만 이용하고 종료한 경우 남은 개월에 대해 아래 기준으로 환불됩니다.

{% hint style="info" %}
**환불 금액 = 결제 금액 − (사용한 기간 금액 + 환불 위약금)**
{% endhint %}

| 항목        | 계산 방식                               |
| --------- | ----------------------------------- |
| 사용한 기간 금액 | 결제한 구독 정기 요금을 12개월로 나눈 금액 × 사용 개월 수 |
| 환불 위약금    | 해당 월 정기 요금의 10%                     |

{% hint style="info" %}
환불 업무는 통상 1\~2 영업일 이내에 처리됩니다. 매입 취소 또는 환불 금액 입금과 관련된 문의는 결제사 또는 카드사로 문의해주세요.
{% endhint %}
