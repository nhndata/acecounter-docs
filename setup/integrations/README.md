# 연동 및 확장

웹사이트 내 사용자 행동(클릭) 및 외부 결제 수단(네이버페이) 연동 등 기본 수집 정보 외에 추가적인 성과 및 이벤트 데이터를 측정하기 위한 가이드 모음입니다.

서비스 특성에 맞춰 필요한 확장 기능을 선택하여 설정해 주세요.



**📌 세부 연동 가이드**

* [클릭 이벤트(링크 클릭) 분석](https://acecounter.gitbook.io/guide/script-setting/event-npay/click-event)
  * 대상: 특정 버튼, 배너, 외부 링크, 전화걸기, 채팅상담등의 링크 클릭 수를 측정하고자 하는 사이트
  * 주요 내용: 웹페이지 내 주요 CTA(Call-to-Action) 버튼 및 클릭 요소에 이벤트 추적 스크립트를 삽입하는 방법
* [네이버페이 연동 가이드](https://acecounter.gitbook.io/guide/script-setting/event-npay/npay)
  * 대상: 네이버페이 주문형 버튼을 통해 상품 구매가 이루어지는 이커머스 사이트
  * 주요 내용: 네이버페이 버튼 클릭 및 구매 완료 데이터를 에이스카운터 전환 성과로 연동하여 분석하는 세팅 방법
