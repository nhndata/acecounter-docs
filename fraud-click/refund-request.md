# 매체별 무효클릭 신청 방법

에이스카운터에서 의심 유입을 확인했다면, 실제 무효클릭 처리는 각 광고 플랫폼의 고객센터를 통해 신고해야 합니다. 매체마다 요구하는 정보와 접수 조건이 다르므로, 신고 전 아래 내용을 참고해 자료를 준비해 주세요.

{% hint style="success" %}
에이스카운터 \[의심유입 진단] 리포트에 표시된 의심 IP와 의심 유입 데이터는 무효클릭 증빙 자료로 활용할 수 있습니다.
{% endhint %}

{% tabs %}
{% tab title="네이버" %}
**위치**: 네이버 고객센터 > 클린센터 > 무효클릭 문의하기 🔗 [네이버 클린센터](https://ads.naver.com/help/cleancenter)

**신고 시 필요 정보**: 클릭일시(날짜/시간), 유입 키워드, 방문한 IP, 방문 URL, 로그 정보 파일(Excel 형식). 대량 신고 시 템플릿을 작성해 첲부할 수 있습니다.

{% hint style="warning" %}
접수일 기준 최근 3개월 이내 데이터만 접수 가능하며, 검토 결과 확인까지 평균 15일이 소요됩니다. 필수 정보가 누락되면 조사가 진행되지 않습니다.
{% endhint %}
{% endtab %}

{% tab title="카카오" %}
**위치**: 카카오 고객센터 > 키워드광고 > 문의하기 🔗 [카카오 공식 가이드](https://kakaobusiness.gitbook.io/main/ad/searchad/keywordad/run/efficiency#id-3-1)

**신고 시 필요 정보**: 클릭일(날짜), 의심 키워드, 의심 IP, 위 정보를 포함한 클릭로그 파일

{% hint style="warning" %}
접수일 기준 최근 1개월 이내 데이터만 접수 가능합니다.
{% endhint %}
{% endtab %}

{% tab title="구글 Ads" %}
**위치**: 구글 고객센터 > 클릭 품질 양식(Click Quality Form) 🔗 [구글 공식 가이드](https://support.google.com/google-ads/answer/42995?hl=ko)

**신고 시 필요 정보**: Google Ads 고객 ID, 무효트래픽 발생 기간(시작/끝), 캐페인명, 광고그룹명, 키워드, 랜딩 URL, 문제 유형, 상세설명. 스크린샷, 로그 파일 등 증빙자료를 첨부할 수 있습니다.
{% endtab %}
{% endtabs %}
